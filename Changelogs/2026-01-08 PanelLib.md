# PanelLib - Panel Container Control Library for Plan9Basic

## Overview

PanelLib provides complete functionality for creating and managing styled container controls in Plan9Basic programs. A Panel is a visual container control with a styled background appearance that can organize child controls with alignment and positioning.

Unlike the Layout (which is invisible), the Panel has a styled visual appearance, making it ideal for creating visible sections, cards, toolbars, and other UI elements that need a visible background.

## Function Count: 82 functions

## Cross-Platform Support

- Windows (Win32/Win64)
- macOS (Intel/ARM)
- Linux
- Android
- iOS

## Features

- Panel creation and lifecycle management
- Comprehensive property access (position, size, alignment, margins, padding)
- Parent/child relationship management
- Visual styled background
- Complete event support with BASIC callback integration
- Full drag and drop support
- Clipping and hit-testing control

## Quick Start

```basic
' Create a simple panel application
let frm# = form#("Panel Demo", 800, 600)

' Create main panel filling the form
let mainPanel# = panel#(frm#)
panel_align#(mainPanel#, 9)  ' Client fill

' Create a header panel at the top
let header# = panel#(mainPanel#)
panel_align#(header#, 1)  ' Top alignment
panel_height#(header#, 60)

' Create a sidebar panel on the left
let sidebar# = panel#(mainPanel#)
panel_align#(sidebar#, 2)  ' Left alignment
panel_width#(sidebar#, 200)

' Create content panel in remaining space
let content# = panel#(mainPanel#)
panel_align#(content#, 9)  ' Client fill

form_show(frm#)
```

## Shift String Format

The shift$ parameter in mouse events contains a string of flags:
- `S` = Shift key
- `C` = Ctrl key
- `A` = Alt key
- `M` = Command key (macOS)
- `L` = Left mouse button
- `R` = Right mouse button
- `X` = Middle mouse button

Example: "SC" means Shift+Ctrl are pressed.

## Panel vs Layout

| Feature | Panel | Layout |
|---------|-------|--------|
| Visual appearance | Has styled background | Invisible |
| Performance | Slightly heavier | Lightweight |
| Use case | UI sections, cards, toolbars | Container organization |
| HitTest default | Enabled | Disabled |

Use Panel when you need a visible container with a background. Use Layout when you need an invisible container for organization only.

## Complete Example

```basic
' Panel Library Demo - Drag and Drop Example

' Create main form
let frm# = form#("Panel Drag & Drop Demo", 800, 600)

' Create source panel (draggable area)
let srcPanel# = panel#(frm#, 50, 50, 200, 150)
panel_onclick#(srcPanel#, "OnSourceClick")

' Create drop target panel
let dropPanel# = panel#(frm#, 300, 50, 300, 400)
panel_ondragenter#(dropPanel#, "OnDropEnter")
panel_ondragover#(dropPanel#, "OnDropOver")
panel_ondragdrop#(dropPanel#, "OnDropDone")
panel_ondragleave#(dropPanel#, "OnDropLeave")

' Status label
let lbl# = label#(frm#, 50, 500, 700, 30)
label_text#(lbl#, "Click source panel to start drag, drop on target panel")

let dragActive = 0

function OnSourceClick(sender#)
  ' Start drag operation
  dragActive = 1
  label_text#(lbl#, "Drag started - move to target panel")
endfunction

function OnDropEnter(sender#, x, y)
  label_text#(lbl#, "Drag entered drop zone")
endfunction

function OnDropOver(sender#, x, y) local accept
  ' Accept the drop
  return 1
endfunction

function OnDropDone(sender#, x, y)
  if dragActive = 1 then
    label_text#(lbl#, "Dropped at X=" + stri$(x) + " Y=" + stri$(y))
    dragActive = 0
  endif
endfunction

function OnDropLeave(sender#)
  label_text#(lbl#, "Drag left drop zone")
endfunction

form_show(frm#)
```

## Memory Management

Panels are automatically managed by the garbage collector. However, for explicit cleanup:

```basic
' Free individual panel
panel_free(pnl#)

' Clear all callbacks before freeing
panel_clearcallbacks#(pnl#)
panel_free(pnl#)
```
