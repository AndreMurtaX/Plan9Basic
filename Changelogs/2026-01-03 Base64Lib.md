# Base64Lib - BASE64 Encoding/Decoding Library

## Overview

The Base64Lib library provides functions for encoding and decoding data using BASE64 encoding. BASE64 is widely used for transmitting binary data in text-based formats such as JSON, XML, email attachments, and data URIs.

**Version:** 1.0  
**Function Count:** 8 functions

---

## Error Handling

All functions in this library set an internal error code that can be retrieved using `b64error()`.

| Error Code | Constant Name | Description |
|------------|---------------|-------------|
| 0 | ERR_NONE | No error |
| 1 | ERR_INVALID_BASE64 | Invalid BASE64 string (malformed or corrupt) |
| 2 | ERR_INVALID_ARGUMENT | Invalid argument (empty path, etc.) |
| 3 | ERR_FILE_ERROR | File read/write error |

### b64error@

Returns the error code from the last Base64Lib operation.

**Signature:** `b64error@`  
**Returns:** Number (error code 0-3)

**Example:**
```basic
encoded$ = b64decode$("invalid!!!")
if b64error() <> 0 then
  println "Decoding failed with error: " + str$(b64error())
endif
```

## Core Functions

### b64encode$@$

Encodes a string to BASE64 format.

**Signature:** `b64encode$@$`  
**Parameters:**
- `input$` - The string to encode (UTF-8)

**Returns:** BASE64 encoded string

**Notes:**
- Empty string input returns empty string (valid case)
- Input is treated as UTF-8 encoded text

**Example:**
```basic
' Encode a simple string
original$ = "Hello, World!"
encoded$ = b64encode$(original$)
println "Encoded: "; encoded$
' Output: Encoded: SGVsbG8sIFdvcmxkIQ==

' Encode text with special characters
text$ = "Olá, Mundo! 日本語"
encoded$ = b64encode$(text$)
println encoded$
```

---

### b64decode$@$

Decodes a BASE64 string back to its original form.

**Signature:** `b64decode$@$`  
**Parameters:**
- `base64$` - The BASE64 encoded string

**Returns:** Decoded string (UTF-8)

**Notes:**
- Returns empty string and sets error code on invalid input
- Handles standard BASE64 with padding (=)

**Example:**
```basic
' Decode a BASE64 string
encoded$ = "SGVsbG8sIFdvcmxkIQ=="
decoded$ = b64decode$(encoded$)
println "Decoded: "; decoded$
' Output: Decoded: Hello, World!

' Round-trip test
original$ = "Plan9Basic is great!"
encoded$ = b64encode$(original$)
decoded$ = b64decode$(encoded$)
if decoded$ = original$ then
  println "Round-trip successful!"
endif
```

## URL-Safe Functions

Standard BASE64 uses `+` and `/` characters which have special meaning in URLs. The URL-safe variant replaces these with `-` and `_`, and removes padding characters (`=`).

### b64urlencode$@$

Encodes a string to URL-safe BASE64 format.

**Signature:** `b64urlencode$@$`  
**Parameters:**
- `input$` - The string to encode

**Returns:** URL-safe BASE64 encoded string

**Notes:**
- Uses `-` instead of `+`
- Uses `_` instead of `/`
- Removes `=` padding characters

**Example:**
```basic
' Standard BASE64 might produce: "a+b/c=="
' URL-safe produces: "a-b_c"

data$ = "user:password"
safe$ = b64urlencode$(data$)
println "URL-safe: "; safe$

' Use in a URL
url$ = "https://api.example.com/auth?token=" + safe$
println url$
```

---

### b64urldecode$@$

Decodes a URL-safe BASE64 string.

**Signature:** `b64urldecode$@$`  
**Parameters:**
- `base64$` - The URL-safe BASE64 encoded string

**Returns:** Decoded string (UTF-8)

**Notes:**
- Automatically restores `+`, `/`, and padding
- Handles both standard and URL-safe BASE64 input

**Example:**
```basic
' Decode URL-safe BASE64
token$ = "dXNlcjpwYXNzd29yZA"
decoded$ = b64urldecode$(token$)
println "Decoded: "; decoded$
' Output: Decoded: user:password
```

## Validation

### b64valid@$

Checks if a string is valid BASE64 format.

**Signature:** `b64valid@$`  
**Parameters:**
- `input$` - The string to validate

**Returns:** 1 if valid BASE64, 0 if invalid

**Notes:**
- Checks for valid characters (A-Z, a-z, 0-9, +, /, =)
- Verifies correct length (multiple of 4)
- Validates padding position and count
- Empty string is considered valid (encodes nothing)

**Example:**
```basic
' Validate before decoding
input$ = "SGVsbG8sIFdvcmxkIQ=="
if b64valid(input$) = 1 then
  decoded$ = b64decode$(input$)
  println "Valid BASE64: "; decoded$
else
  println "Invalid BASE64 string!"
endif

' Test various inputs
println "Empty: " + str$(b64valid(""))
println "Valid: " + str$(b64valid("YWJj"))
println "Invalid: " + str$(b64valid("abc!"))
println "Bad length: " + str$(b64valid("abc"))
```

## File Operations

### b64encodefile$@$

Reads a binary file and encodes its contents to BASE64.

**Signature:** `b64encodefile$@$`  
**Parameters:**
- `filepath$` - Path to the file to encode

**Returns:** BASE64 encoded file contents, or empty string on error

**Notes:**
- Can encode any file type (images, documents, executables, etc.)
- Sets ERR_FILE_ERROR if file cannot be read
- Sets ERR_INVALID_ARGUMENT if path is empty

**Example:**
```basic
' Encode an image file
imagePath$ = "photo.jpg"
encoded$ = b64encodefile$(imagePath$)

if b64error() = 0 then
  println "File encoded successfully"
  println "Length: " + str$(len(encoded$)) + " characters"
  
  ' Create a data URI for HTML
  dataUri$ = "data:image/jpeg;base64," + encoded$
else
  println "Error encoding file: " + str$(b64error())
endif
```

---

### b64decodefile@$$

Decodes a BASE64 string and writes the binary data to a file.

**Signature:** `b64decodefile@$$`  
**Parameters:**
- `base64$` - The BASE64 encoded data
- `filepath$` - Path where to save the decoded file

**Returns:** 1 on success, 0 on failure

**Notes:**
- Creates a new file or overwrites existing file
- Sets ERR_INVALID_BASE64 if input is malformed
- Sets ERR_FILE_ERROR if file cannot be written
- Sets ERR_INVALID_ARGUMENT if path is empty

**Example:**
```basic
' Decode BASE64 data to a file
base64Data$ = "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg=="
outputPath$ = "pixel.png"

result = b64decodefile(base64Data$, outputPath$)

if result = 1 then
  println "File saved successfully!"
else
  println "Error saving file: " + str$(b64error())
endif
```

### Example 3: File Round-Trip

```basic

println ""

tempBase64$ = ""

  println "Error reading file!"

' Decode to new file

  println "File copied successfully via BASE64!"
else
  println "Error writing file!"
endif
```

## What is BASE64?

BASE64 is an encoding scheme that converts binary data into a text format using 64 printable ASCII characters. It's commonly used when binary data needs to be transmitted over systems designed to handle text.

**Character Set:**
- `A-Z` (26 characters)
- `a-z` (26 characters)  
- `0-9` (10 characters)
- `+` and `/` (2 characters)
- `=` (padding character)

**How it works:**
1. Take 3 bytes (24 bits) of input
2. Split into 4 groups of 6 bits each
3. Convert each 6-bit group to one BASE64 character
4. If input isn't divisible by 3, add `=` padding

**Size increase:** BASE64 encoding increases data size by approximately 33% (4 output characters for every 3 input bytes).
